# TRAIN LOG V2.2 LOCAL

私人健身训练日志，本版本不使用 D1 或任何云数据库。

## 数据保存
- 所有训练、身体数据、计划、饮食设置均保存在当前设备浏览器 localStorage。
- 我的 → 设置 → 一键备份：导出完整 JSON 备份。
- 我的 → 设置 → 一键恢复：选择 JSON 备份文件恢复全部数据。

## 动作媒体
- 63 个内置动作均配置 Gym Visual 数据库匹配规则，动作库、计划、训练、历史、详情统一使用对应循环 GIF。
- 动作详情均包含 TRAIN LOG 内置中文短教学：直接在当前页面播放，以 Gym Visual 动作循环画面配合中文动作要点，避免跳转 B 站/抖音。
- 训练肌群图使用统一正/背面模板：红色主肌群、橙色辅助肌群、白/灰非主要肌群。

## 部署
这是纯静态 PWA。直接覆盖 GitHub 仓库后由 Cloudflare 自动部署即可，不需要 D1、Worker API、数据库绑定或 wrangler 配置。
